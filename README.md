# AirAware

AirAware is an air-quality dashboard for exploring AQI and pollutant readings
across cities in Maharashtra.

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

The frontend entry point is `src/main.jsx`. Keep the `src` and `public`
directories in the project root so Vite can resolve the application files.
